# GoldenHour AI — Hackathon 3D Medical Asset Library
> **Mivo Liquid Glass Medical Aesthetic (RonDesignLab Master Specification)**
> Built for the GoldenHour AI Emergency Coordination Hackathon Prototype & Full Production Build.

This directory contains the complete suite of photorealistic, medical-grade 3D renders generated for GoldenHour AI. Every asset adheres strictly to the RonDesignLab Mivo healthcare design language: Octane raytraced glass physics, subsurface scattering, chromatic dispersion, warm porcelain/peach/rose ambient lighting, and generous negative space.

## Design System Integration Principles

1. **Never Lock in Constricting Frames**:
   Do not trap these 3D objects inside cramped fixed-pixel boxes, tiny button icons, or collapsed dropdown toggles. Let the assets breathe with generous negative space, soft gradient falloffs (`mask-image: radial-gradient(...)` or `from-transparent via-transparent to-slate-900/40`), and unconstrained layout proportions.

2. **Floating Liquid Glass Telemetry Overlays**:
   Overlay data using RonDesignLab stadium pills (`border-radius: 9999px`, `backdrop-filter: blur(16px)`, `background: rgba(255,255,255,0.85)` or frosted dark glass) so the telemetry floats organically on top of the 3D asset rather than pushing the asset offscreen.

3. **Color Tokens**:
   - `Radiant Rose`: `#F43F5E` / `rgba(244, 63, 94, 0.15)`
   - `Warm Amber`: `#F59E0B` / `rgba(245, 158, 11, 0.15)`
   - `Neon Lime Accent`: `#D4FF00` (used for high-priority status badges and active metrics)
   - `Porcelain White`: `#FAF9F6` / `rgba(255, 255, 255, 0.75)`
   - `Glass Specular Border`: `border: 1px solid rgba(255, 255, 255, 0.5)` with `box-shadow: inset 0 1px 1px rgba(255, 255, 255, 0.6)`.
